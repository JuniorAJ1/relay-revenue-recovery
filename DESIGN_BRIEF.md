# Relay: shareable working-platform preview

Audience: a high-ticket sales owner, sales manager and the people handling recovery.
Purpose: make the product easy to understand and credible in a short first look.
Main action: find a flagged opportunity, inspect its history, and try the next step.
Direction: a calm, professional operations workspace; white surfaces, ink text,
restrained emerald accents and colour used consistently for statuses. A structured
sidebar, compact metrics, generous chart space, readable table rows and a focused
lead review panel. Follow the supplied finance/operations dashboard references.

Keep all existing lead, approval, appointment and cash rules working. The public
preview runs those server rules using fictional, browser-held workspaces, with no
live credentials, shared customer database, live sends or actual payments. Make
that context visible. Visitors can reset their own sample workspace.

Inspect desktop and mobile, keyboard focus, empty/filter states, a complete sample
workflow, route navigation, layout overflow and contrast. Avoid simulated live
connection badges, unsupported lift/revenue claims and distracting motion.
